# Technical Debt

decision someone already made, not a task that fell through — if an entry has no
owner or trigger below, it is not being tracked properly.

Add an entry when a discovery does not fit in a code comment or a spec, and leave
it here when it is closed rather than deleting the row, so the reasoning survives.

## Resolved

| Item                                                              | Resolution                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Whitespace-only input persisted as `''` in required string fields | Fixed in `0371af5`. `Field(min_length=1)` did not protect string fields, because Pydantic checks `min_length` before an `after`-mode validator runs — so `"   "` passed the length check and was trimmed to `""`. Thirteen required fields were affected, reachable through the live API. The helpers now live in `app/schemas/validation.py` (`strip_text` rejects blank, `strip_optional` still allows it), and `tests/test_schema_validation.py` enforces the invariant structurally so a new request schema cannot reintroduce it. Residual data remediation is tracked as item 4. |
